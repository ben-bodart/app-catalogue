# APP CATALOGUE

## 🕹️ Catalogue de Jeux Vidéo

Application en ligne de commande développée en Python, permettant de gérer une collection personnelle de jeux vidéo (ajout, modification, suppression, recherche) via un fichier JSON.

Premier projet complet, réalisé durant l'été 2026 dans le but d'apprendre à manipuler Python et JSON ensemble, et de revoir les bases du langage.

---

## Fonctionnalités

- 📋 Afficher le catalogue (trié par nom, console ou genre)
- ➕ Ajouter un jeu
- 🔄️ Modifier un jeu existant
- 🗑️ Supprimer un jeu
- 🔍 Recherche en temps réel avec navigation au clavier (flèches, sélection)

---

## Lancer le projet

Prérequis : Python 3

\`\`\`bash
git clone https://github.com/<ton-pseudo>/<nom-du-repo>.git
cd <nom-du-repo>
python app_catalogue_jeux.py
\`\`\`

Un fichier \`fichier.json\` pré-rempli est fourni pour tester l'application directement.

---

## Ce que ce projet m'a permis de pratiquer

- Lecture/écriture de fichiers JSON avec Python
- Structuration d'un menu interactif en boucle
- Gestion des entrées utilisateur et des cas d'erreur
- Tri et filtrage de données

Certaines fonctionnalités plus complexes (navigation clavier en temps réel) ont été développées avec l'aide d'une IA.
